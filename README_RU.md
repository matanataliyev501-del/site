# FORTUNA APPS — ГОТОВЫЙ САЙТ ДЛЯ GITHUB PAGES

## Что исправлено

- Внутри каждой страницы уже есть CSS и JavaScript — сайт не зависит от загрузки отдельных папок `assets`.
- Красивые адреса без `.html`: `/careers/`, `/start-a-project/`, `/what-we-do/` и т. д.
- Каждая страница — собственная папка с `index.html` — это работает на GitHub Pages без переадресаций, фреймворков и серверной части.
- EN + PL, оба языка с полным набором страниц, мобильное меню, фильтр направлений вакансий.
- Работает как на собственном домене, так и на адресе `username.github.io/имя-репозитория/`.

## Как залить вместо старого сайта

1. Откройте ваш репозиторий GitHub и **удалите старые файлы** сайта: `about.html`, `careers.html`, `index.html`, `start-a-project.html`, старые HTML-файлы в `pl/`, папку `assets/` и т. д. Старые страницы можно удалить, но **не удаляйте CNAME**, если настроен собственный домен.
2. Распакуйте данный ZIP. Вы увидите `index.html`, `.nojekyll`, папки `about`, `careers`, `contact`, `goals`, `pl`, `privacy`, `process`, `start-a-project`, `what-we-do` и README.
3. Загрузите **всё содержимое архива** в **корень** репозитория. В GitHub можно перетащить содержимое папки в Add file → Upload files; убедитесь, что сохраняются вложенные папки. Или загрузите файлы через Git/GitHub Desktop, чтобы точно сохранить структуру.
4. В Settings → Pages проверьте: Deploy from a branch → main → / (root).
5. Откройте ссылку сайта; обновите страницу с обходом кеша (Ctrl+Shift+R / Cmd+Shift+R). Навигация должна вести на `.../careers/`, а не на `.../careers.html`.

> ВАЖНО: для красивых URL вложенные папки должны попасть в репозиторий. Например, у вас должен быть файл `careers/index.html`, **а не** только `careers.html`.

## Формы

Формы заявок отправляются через стороннюю службу FormSubmit на **hello@fortuna-apps.com**. После первой отправки требуется подтвердить адрес получателя через письмо от FormSubmit; проверьте спам. Только после подтверждения и реального теста доставки считать приём заявок настроенным. GitHub Pages самостоятельно не отправляет письма.

Проверьте политику конфиденциальности у юриста перед публикацией: анкеты собирают персональные данные, передаваемые стороннему обработчику. Вакансии обозначены как направления инициативных заявок, а не реальные открытые позиции.
